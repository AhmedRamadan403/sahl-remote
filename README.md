# سهل ريموت — Sahl Remote

تطبيق مستقل للتحكم في كمبيوتر ويندوز من موبايل أندرويد أو من كمبيوتر آخر على نفس الشبكة المحلية، باستخدام QR أو رقم اتصال مؤقت وموافقة من الكمبيوتر.

**[صفحة التحميل](https://ahmedramadan403.github.io/sahl-remote/) · [ملفات الإصدار](https://github.com/AhmedRamadan403/sahl-remote/releases/tag/v0.3.1)**

## ابدأ الاستخدام

1. حمّل **SahlRemote-Desktop.exe** على الكمبيوتر، وافتحه واضغط **Start sharing**.
2. ثبّت **SahlRemote-Android.apk** على أندرويد، وافتح سهل ريموت.
3. وصّل الجهازين بنفس الواي فاي وامسح QR الكمبيوتر من داخل التطبيق، أو اكتب رقم الاتصال.
4. وافق من الكمبيوتر بزر **Allow device**، ثم فعّل التحكم من الموبايل.
5. زر **خروج ×** أو **Ctrl+Q** يغلق البرنامج كله، و**Stop sharing** يوقف المشاركة.

**لا تكتب IP يدويًا:** البرنامج يكتشف عنوان كل كمبيوتر وقت بدء المشاركة، والـQR يحمل عنوانه ورمزًا مؤقتًا وبصمة شهادته. البحث بالرقم يكتشف الكمبيوتر داخل الشبكة تلقائيًا. بعد تغيير شبكة الكمبيوتر، أوقف المشاركة وابدأها مجددًا لتحديث العنوان والـQR. شبكات الضيوف قد تمنع اتصال الأجهزة ببعضها.

صفحة GitHub متاحة للتحميل من الإنترنت، أما التحكم في هذا الإصدار فداخل نفس الشبكة فقط. الكمبيوتر المضيف يظل مفتوحًا أثناء جلسة التحكم. الاتصال عبر الإنترنت مؤجل وغير موجود في هذا الإصدار.

## المكونات

| المسار | الاستخدام |
| --- | --- |
| `Desktop/` | مضيف ويندوز بـPython وواجهة CustomTkinter ونقل HTTPS/WSS |
| `Mobile/` | تطبيق Flutter/Dart؛ حزمة أندرويد قابلة للتثبيت |
| `docs/` | صفحة تحميل ثابتة لـGitHub Pages، لا تحتاج Python على الاستضافة |

ملف EXE مستقل ولا يحتاج Python على جهاز المستخدم. الإصدار الحالي: Windows **0.3.1**، Android **0.2.0**.

## البناء والاختبارات

راجع [دليل ويندوز](Desktop/README-AR.md) و[دليل Flutter](Mobile/README-AR.md). بعد تثبيت المتطلبات يمكن تشغيل اختبارات المضيف بـ`python -m unittest discover -s Desktop/tests -v`، وتحتاج اختبارات فك QR حزمة `zxing-cpp`. بناء EXE متاح عبر `Desktop/build.ps1`، وبناء APK عبر `flutter build apk --release` داخل `Mobile/`.

هذه نسخة تجريبية. اجتازت 55 اختبار Python وفحص EXE المجمّع. اختبارات الشاشة والإدخال استخدمت صورًا وواجهات اصطناعية؛ تجربة موبايل فعلي وشاشة UAC تظل تحققًا يدويًا. UAC يتطلب الموافقة من الكمبيوتر؛ تبقى الجلسة متصلة أثناء تعذر التقاط الشاشة مؤقتًا. EXE غير موقّع بشهادة ناشر، وAPK تجريبي بتوقيع التطوير. مشروع iOS مرفق في المصدر لكنه لم يُبنَ أو يُختبر.

## الخصوصية

التقاط الشاشة والإدخال يبدآن بعد الموافقة المحلية، وجلسة واحدة فقط مسموحة. QR يحتوي رمزًا مؤقتًا؛ المفتاح الخاص بالشهادة يُنشأ محليًا لكل مستخدم ولا يُنشر هنا. لا يوجد تشغيل تلقائي أو خدمة خلفية، وتنتهي المشاركة والتحميل المحلي عند إغلاق النافذة. ملفات `Mobile/test/fixtures/` شهادة ومفتاح **اختبارات محلية اصطناعية فقط** وليست بيانات اعتماد إنتاج.
